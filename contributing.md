# Contribution Guidelines

Please note that this project is released with a [Contributor Code of Conduct](code-of-conduct.md). By participating in this project you agree to abide by its terms.

## Adding to this list

- Search previous suggestions before making a new one.
- Only suggest projects you have personally used or can vouch for — this is a curation, not a directory.
- Make an individual pull request for each suggestion.
- Use the format: `- [owner/repo](https://github.com/owner/repo) - Description. ⭐ 12.3k`
- New entries go in the most relevant section, ordered by GitHub stars (descending).
- Keep descriptions short and factual. End them with a period.
- Check your spelling and grammar.
- Remove trailing whitespace.

## Updating your pull request

If maintainers notice something that needs changing, they'll ask you to edit your PR before merging. There's no need to open a new one — just push more commits to your branch.
